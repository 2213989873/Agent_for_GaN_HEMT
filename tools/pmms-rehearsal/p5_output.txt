# optimize / start_optimize 参数填写指南（model_source_name + param_string）

> 本文档面向 MCP Agent：说明 `optimize` / `start_optimize` 的 `model_source_name` 与 `param_string` 两个参数如何填写，才能正确选中参与优化的模型参数。
>
> 接口把模板里的 `param global(...)` / `param param(...)` 拆成两部分：
> - `model_source_name`：**必填**，模型源名（模板中 param 行的首段模型变量名在接口里对应模型源名）；
> - `param_string`：**必填**，只填参数名列表（不含模型源名），等价于模板 param 行去掉 `param <key>(`、`)` 与首段模型名之后剩下的参数列表。
>
> 服务端会自行组装为内部串「模型源名,参数名,...」（如 `nmos_N,vth0,u0`），Agent 无需拼首段。
>
> 相关工具：`list_model_sources`（取模型源名）、`list_params`（取可用参数名）、
> `view`（构图，使用优化时必须提供 `selection_string`）、
> `start_optimize` + `get_job_status`（异步优化；同步入口为 `optimize`）。

> **⚠ Agent 硬性规则（最重要）**：
> 1. **必须传 `model_source_name`**——它是独立必填字段，不再是 `param_string` 的首段。
>    用户通常只报参数名（如"优化 vth0、u0、ua、ub"），模型源名须自行取得：
>    来源优先级：① 用户/上下文已给的模型源名 → ② 本次 `view` 的 `source_string` 第二段 →
>    ③ `list_model_sources` 查询。
> 2. **`param_string` 只填参数名，禁止再带模型源名**，也禁止传空。
>    正确：`model_source_name=nmos_N`、`param_string=vth0,u0`；
>    错误：`param_string=nmos_N,vth0,u0`（模型源名重复，应放到 `model_source_name`）。
> 3. PMMS 会校验 `model_source_name` 必须是已加载的模型源名，否则直接报错返回，不再静默跳过。
>    参数名写错仍会被服务端静默跳过（只表现为"优化没效果"），故参数名务必照抄 `list_params`。

## 1. 两个字段的格式

```
model_source_name: <模型源名>                              # 例：nmos_N
param_string:      <参数名1>[,<参数名2>...][,device(<实例=值>...,<器件级参数名>...)]
```

- `model_source_name` 与 `view` 的 `source_string` 中的 `model_source_name` 一致，可用 `list_model_sources` 查询；
- `param_string` 用**英文半角逗号** `,` 分隔，段内不要加空格；
- **不要**在 `param_string` 里写模型源名，也**不要写** `param` / `global` / `param(...)` 等关键字与外层括号；
- `param_string` 仅普通参数名时，作用于模型 bean/para 参数；`device(...)` 段用于 binning/copy 的器件级参数（见 §5）。

## 2. 与模板 §13.2 param 行的对应关系

| 模板 param 行（§13.2 完整写法） | model_source_name | param_string |
|---|---|---|
| `param global(Model, vth0, u0, ua, ub)` | `Model` 对应的模型源名（如 `nmos_N`） | `vth0,u0,ua,ub` |
| `param param(Model, avth0)` | 同上 | `avth0` |
| `param param(rfmodel,${cgdext_rf})` | rfmodel 对应模型源名 | `cgdext_rf`（`${token}` 已展开） |
| `param device(Model1, w=10, l=10) copy(Model, cgs0)` | Model 对应模型源名 | `cgs0` 或 `device(w=10,l=10,cgs0)` |

要点：

- 模板 param 行的首段是**模型变量名**（如 `Model`、`rfmodel`）；在 optimize 接口中该角色由独立的 `model_source_name` 承担（填**模型源名**，如 `nmos_N`）；
- 服务端在候选参数集合（ModelBean + ModelPara + DeviceCopy）中自动匹配 `param_string` 中的参数名。
