## ✅ 实战存档（run_qa_selfheat.py，两参数起步）

```
两参数:   voff=-2.306 u0=0.1223 → NRMSE=1.69%，QA 通过但未达 1% → 触发器2 点火，扩 rontr1
三参数:   +rontr1=-0.804 → NRMSE=0.60% < 1% → 收工
```

**三参数解 (-2.238, 0.135, -0.804) 仍非真值**——rontr1+u0 联手把自热下垂
（本不属于它们的现象）近似吸收。这是"够用但不真"的又一次现身。

**四参数对照验证**（直接 least_squares，含 rth0）：
```
349 次仿真 40s：voff=-2.2, u0=0.14999, rontr1=-0.99989, rth0=19.986
NRMSE=0.0003% —— 四参数空间覆盖真值 ✅
```

## 核心账：RMSE_TARGET 是"够用 vs 追真"的旋钮

| 方案 | NRMSE | 仿真成本 | 参数 |
|---|---|---|---|
| 三参数收工（阈值1%） | 0.60% | 15 次仿真 | 近似（自热被吸收） |
| 四参数追真（阈值0.05%） | 0.0003% | **349 次仿真（23×）** | 全命中 |

赛题评分只看 RMSE×QA 不看真值命中——0.60% 已是高分。
但任务 3 的外推教训：近似解在隐藏网格上有反弹风险。
**阈值与时间预算挂钩**：仿真便宜（本地秒级）就追低阈值；赛题真实数据
（万级网格、秒级单次仿真）下 349 次仿真≈数十分钟，需分区预算。
