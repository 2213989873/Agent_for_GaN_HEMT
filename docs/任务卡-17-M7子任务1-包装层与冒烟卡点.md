## 4. 已排除项（每条有实证）

1. **suite 状态跨实例不持久**：pnano 预热实例报 "model suite not loaded: 1"——每次会话须先 load_model，已遵守；
2. **调用顺序**：p4 用 get_prompt 取回官方 `project_initialization` Prompt 原文，顺序 generate_project→load_model→add_model_source→load_data 与我们的调用一致（add_model_source 用默认值、先于 load_data）；
3. **模型文件**：jia.inc 与官方 `etc/demo/model/demo.lib` 均 load_model 成功、list_available_models 正常，排除模型文件本身；
4. **参数形态**：缺省/显式 lib+model/顶层 corner 段名（tt）三变体同败，排除参数用法。
