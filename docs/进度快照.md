## 9. 核心概念速查（详解见 docs/器件知识速成.md、本快照下方聊天记录）

- **Verilog-A** = 模型的乐谱（人读写）→ **OpenVAF** = 刻录机 → **.osdi** = CD（机器可执行）→ **OSDI** = ngspice 上的标准 CD 口（≥39 且编译时 `--enable-osdi`）→ **ngspice** = 播放器（仿真出数据）
- LangGraph：state（共享黑板）/ node（干活函数）/ edge（走线）/ 条件边（if 判断流向）；手写循环里 `messages` ≈ state，`if not msg.tool_calls` ≈ 条件边
- MCP：Client 连 Server 握手后 `list_tools` 发现工具 → `call_tool` 调用；赛题 = 组委会 MeQLab 当 Server，我们的 Agent 当 Client
- 器件：Vth（阈值电压）、gm（跨导）、自热（高功率下曲线下垂）、陷阱（直流 vs 脉冲 I-V 差异）、分区提参（120 参数分区域各管一段）
