# 名词手册（小白版）

> 遇到新名词先查这里；没有的就问 Kimi 并补充进来。持续更新。

## 器件与物理

| 名词 | 一句话解释 |
|---|---|
| GaN | 氮化镓，第三代半导体材料，耐高压、高频、高效率 |
| HEMT | 高电子迁移率晶体管，GaN 器件的主流结构 |
| 阈值电压 (Vth) | 让晶体管"开始导通"的栅极电压 |
| 线性区 / 饱和区 | I-V 曲线的两个阶段：电流随电压线性上升区 / 电流趋于平稳区 |
| 自热效应 | 器件大功率工作时自己发热，导致电流下降（曲线回滞） |
| 陷阱效应 | 电子被材料缺陷"困住"，导致电流响应变慢、迟滞 |
| 场板 | 改善电场分布的金属结构，影响击穿和电容 |

## 建模

| 名词 | 一句话解释 |
|---|---|
| 紧凑模型 | 用一组公式+参数描述器件电气行为的数学模型 |
| ASM-HEMT | GaN HEMT 的唯一业界标准紧凑模型，约 120 个参数 |
| 模型卡 | 填好全部参数值的文件，SPICE 仿真器直接调用 |
| 参数提取 | 从测量数据反推模型参数值的过程（本赛题的核心） |
| SPICE | 电路仿真器的事实标准；NanoSpice 是概伦的国产仿真器 |
| 拟合 | 调参数让模型曲线尽量贴合测量曲线 |
| RMSE | 均方根误差，衡量"模型曲线 vs 真实曲线"的差距，越小越好 |

## 四种测量数据

| 名词 | 测什么 |
|---|---|
| 直流 I-V | 静态电流-电压特性 → 提取直流参数（Vth、电阻、迁移率等） |
| C-V | 电容-电压特性 → 提取电荷/电容参数 |
| 脉冲 I-V | 微秒级快速测量 → 暴露陷阱与自热效应 |
| S 参数 | 射频小信号散射参数 → 提取寄生与高频参数 |

## AI 工程

| 名词 | 一句话解释 |
|---|---|
| Agent | 能自主规划、调用工具、多轮迭代的大模型程序 |
| LangGraph | 状态机式 Agent 框架，用"节点+边"描述决策流程 |
| deepagents | 轻量级规划式 Agent 框架（本赛题另一可选项） |
| MCP | Model Context Protocol，大模型调用外部工具的标准协议 |
| function calling | 大模型"请求调用某个函数"的能力，是工具调用的基础 |
| checkpoint | 状态持久化：流程中途存盘，崩了能续跑 |
| token | 大模型的计费/长度单位，1 个汉字约 1–2 token |
| State（LangGraph） | 在节点间接力传递的共享记事本，流程的唯一事实来源 |
| Reducer | state 字段的合并规则（如 operator.add = 追加而非覆盖） |
| 条件边 | 读 state、返回下一节点名字的路由函数，实现"QA 失败回退"这类分支 |
| AIMessage.tool_calls | 模型的"决策单"：要调哪个工具、参数是什么 |
| ToolMessage | 工具的"执行回执"：调用结果，靠 tool_call_id 与决策单配对 |
