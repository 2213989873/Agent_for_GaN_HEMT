# 器件知识速成（赛题专用最小清单）

> 目标读者：不懂电子的你。目标：够设计 Agent 流程和 prompt，不是成为器件专家。
> 读法：通读一遍 → 做任务 03 的画图练习 → 回头再读一遍。约 30 分钟。

## 1. 晶体管是什么：电压控制的水龙头

HEMT 有三个端子：**栅极 G（阀门手柄）、漏极 D（进水口）、源极 S（出水口）**。

- 栅压 **Vgs** 控制阀门开度 → 决定能流多大电流
- 漏压 **Vds** 是水压 → 推动电流从 D 流向 S
- 电流 **Id** 就是水流量

所有建模工作，本质是回答一个问题：**给定任意 (Vgs, Vds, 温度)，Id 是多少？**（以及电容是多少、高频特性如何）。

## 2. 输出特性曲线（Id-Vds）：最重要的一张图

固定 Vgs 为几个档位，各扫一遍 Vds，得到一族曲线：

```
Id ↑
   │ Vgs=6V  ╭────────╮﹏        ← 高功率处微微下弯 = 自热
   │ Vgs=5V  ╭──────╮﹏
   │ Vgs=4V  ╭────╮
   │ Vgs=3V  ╭──╮
   │ Vgs=2V ╭╮
   │       ╱ │
   │ 线性区╱  │ 饱和区（平台）
   └───────────────→ Vds
        拐点：Vdsat
```

- **线性区**（Vds 小）：电流随 Vds 近似线性上升，器件像个电阻 → 斜率反映**沟道电阻/迁移率**参数
- **拐点**：进入饱和的分界 → 反映**饱和电压**参数
- **饱和区**（Vds 大）：电流基本平稳 → 平台高度由 Vgs 决定；平台若有斜率，反映**沟道长度调制/输出电阻**
- **自热下弯**：大功率点电流反而下降（红线处）→ GaN 特色，对应**自热参数**（热阻 Rth、热容 Cth）

## 3. 转移特性曲线（Id-Vgs）：找阈值

固定 Vds，扫 Vgs：

```
Id ↑
   │          ╱
   │         ╱
   │       ╱
   │   ___╱
   └──┴───────→ Vgs
     Vth
```

- **Vth（阈值电压）**：电流"开始起来"的栅压，曲线拐点切线与横轴交点。提取参数时**第一个要定的就是它**
- 曲线陡峭程度 = 跨导 gm = "栅控能力有多强" → 反映**迁移率、栅电容**参数

## 4. C-V（电容-电压）：看不见的电荷

栅极与沟道之间有电容，且随 Vgs 变化（沟道形成前后电容突变）。C-V 曲线长这样：低压时电容小，过了 Vth 电容陡增到平台。

- 用途：提取**电容/电荷参数**（Cgs、Cgd 相关的模型参数组）
- 为什么单独测：直流 I-V 只反映"电流"，不反映"电荷"，而射频性能强烈依赖电容

## 5. 脉冲 I-V：抓"活的"缺陷

直流测量时，器件有时间发热、陷阱有时间抓电子——测到的是"稳态"。**脉冲 I-V** 用微秒级短脉冲测量，快到自热和陷阱来不及反应：

- 脉冲结果 vs 直流结果的**差异** = 自热/陷阱效应的大小
- GaN 的招牌问题"**电流崩塌**"（current collapse）：加过高压后电流回不来，就是陷阱在作怪
- 用途：提取**陷阱参数**（能级、时间常数）和**自热参数**

## 6. S 参数：射频世界的语言

频率高到 GHz 后，电压电流概念让位于"波"。S 参数描述器件对入射波的反射（S11、S22）和传输（S21 = 增益、S12 = 隔离）。

- 用途：提取**寄生参数**（焊盘电容、引线电感、栅电阻 Rg）和验证小信号模型
- 你只需要记住：S 参数拟合的是**高频小信号行为**，是射频模型的试金石

## 7. ASM-HEMT 参数分组地图（~120 参数的全景）

| 参数组 | 物理意义 | 主要数据来源 |
|---|---|---|
| 直流核心 | Vth、迁移率、饱和速度、沟道电阻 | 直流 I-V |
| 接入电阻 | 源/漏寄生电阻 Rs、Rd | 直流 I-V 线性区 |
| 电容电荷 | Cgs/Cgd 相关电荷模型参数 | C-V |
| 自热 | 热阻 Rth、热容 Cth | 脉冲 I-V vs 直流 I-V |
| 陷阱 | 陷阱能级、俘获/释放时间常数 | 脉冲 I-V |
| 射频寄生 | Rg、引线电感、焊盘电容 | S 参数 |
| 场板/击穿 | 高压电场相关 | 高压 I-V |

**这张表就是未来"知识表 1-提参顺序"的骨架**：每组参数用对应的数据提，按"直流 → 电容 → 脉冲 → 射频"的顺序，提完一组锁一组。

## 8. 参数提取的本质（把前面全部串起来）

1. **分而治之**：不存在"一次调 120 个参数"，永远是按参数组、用对应数据、分模块拟合
2. **先粗后精**：初值估计（如从曲线拐点读 Vth）→ 局部优化 → 全局微调
3. **锁定前进**：提完的参数冻结，进入下一组；最后才允许小范围全局 retune
4. **物理 QA 兜底**：拟合得好≠物理合理。单调性（Id 必须随 Vgs 增大）、对称性（D/S 互换）、kink（异常拐点）、参数范围（电阻不能为负）都要查

**你的 Agent 干的事**：把 1–4 这套专家流程变成状态机，让 LLM 在每一步做"下一步做什么、满意不满意、不满意怎么修"的决策。
