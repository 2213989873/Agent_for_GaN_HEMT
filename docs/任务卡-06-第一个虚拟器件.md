✅ **已完成（2026-09-16），结果存档**：

- `.osdi` 位置：`VA-Models/code/ASMHEMT/vacode/asmhemt.osdi`
- 目录内容：仅源码 + 许可证 + Changelog，**无官方测试网表/参考数据**（没作业可抄，自己写）
- **引脚定义：`module asmhemt(d,g,s,b,dt);`——5 个脚**：
  - `d/g/s` = 漏/栅/源（老三样）
  - `b` = 衬底（bulk），本赛题场景直接接地
  - **`dt` = 热节点（自热效应的对外接口）**——这是电热模型的标准玩法：模型把"耗散功率"当**电流**从 dt 推出来，dt 上的**电压**就是"结温升幅 ΔT"。所以：`dt 直接接地` = ΔT 恒 0 = **关自热（甲器件的标准接法）**；`dt 经电阻 Rth 接地` = ΔT = P×Rth = **开自热，Rth 就是自热强度的旋钮（乙器件靠它）**

### ② 最小网表（30–60 分钟）

在 `data/sim/` 下建 `smoke_transfer.sp`：

```spice
* ASM-HEMT 冒烟测试：转移特性 Id-Vg（甲器件 = 全默认参数 + 关自热）
Vd d 0 5
Vg g 0 0

* 5 个脚 d g s b dt：s、b 接地；dt 直接接地 = ΔT=0 = 关自热（等温工作）
N1 d g 0 0 0 asmhemtdev
.model asmhemtdev asmhemt ()

.control
pre_osdi /data/zhengjp/gan-hemt-agent/data/sim/VA-Models/code/ASMHEMT/vacode/asmhemt.osdi
dc Vg -2 6 0.1
wrdata transfer.csv i(vd)
.endc

.end
```

跑：`ngspice -b smoke_transfer.sp`

⚠️ 预期要迭代几轮，别怕：

- 报错就把**完整输出**贴给 Kimi（高发区：模型类型名大小写、pre_osdi 路径写错、`.model` 行空括号不被接受就去掉括号）
- `i(vd)` 是"流进电压源正极"的电流 = **漏极电流的负值**，画图时取负，别被负电流吓到（SPICE 符号约定，正常现象）
- 想提前偷看自热？把 N1 第 5 脚从 `0` 改接到一个叫 `dt` 的节点，再加一行 `Rth dt 0 50`（50 K/W），重跑——高 Vd 大电流区域的曲线下垂就是自热。这是乙器件的预演，跑不跑随意
