## Part B：DC 输出特性纳入拟合（run_qa_output.py，847 点）

目标 `dc_output_yi_iso.csv`（乙全处方**等温**版——自热刻意排除，热参数族留卡 13）。
qa_loop 泛化：State 新增 `sim_fn` 字段，QA 闭环与数据形态解耦。

**结果（两参数起步）**：
```
optimize(9次仿真): voff=-2.2898 u0=0.13049 → NRMSE=1.95%
physics_qa: ✅ 通过（u0=0.1305 ∈ [0.1, 0.25] 范围内！）
```

**新发现——补偿解 QA 漏网**：输出特性形态下补偿解 (voff=-2.29, u0=0.1305)
不再出界（转移特性形态下 u0=84e-3 出界被拦）。即：**补偿解依赖观测协议**，
换数据形态后单参数范围 QA 存在盲区。参数不真（u0 差 13%，voff 差 0.09V）但
NRMSE 1.95% 尚可——这是"可用但不真"的灰色地带。

**对照验证**（直接三参数 least_squares）：0.0000% 精确命中真值（19 次仿真）——
三参数空间对输出特性同样覆盖真值 ✅。

## 设计问题浮出（进 Phase 3 规范）

expand 当前只有"QA 驳回×2"一个触发器。Part B 证明需要第二触发器：
**QA 通过但 NRMSE 未达目标**（如 >1%）时，应允许 expand 继续扩空间——
否则 pipeline 会满足于"QA 漏网的补偿解"。双触发器设计留任务卡 13 实现。
