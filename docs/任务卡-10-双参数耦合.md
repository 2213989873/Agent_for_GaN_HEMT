- **前置条件**：任务卡 09（单参数闭环 + 三件套）

## 目标

从单参数升到两参数（voff + u0 同时提），目标器件=乙（真值 voff=-2.2, u0=150e-3）。
学会建模的真正难题：参数效果互相纠缠，单看曲线分不清谁错了。

## 三幕实验实录（全部实测，无一行猜测）

### 第一幕：裸 LLM 双参数（run_dual.py v1）
NRMSE 单调下降 11.4%→7.86%（三件套生效），但 10 轮卡在假最优
voff=-2.10/u0=135e-3：voff 偏正导致起流偏早，u0 被压低背锅补偿。
**症状**：LLM 反复念叨"起流点在 -2.5~-2 之间"——采样点太稀，判断不了精确位置。

### 第二幕：加密采样 + 坐标下降铁律（v2）
过渡区采样加密后 LLM 首轮就锁定"起流点 -2.4~-2.3"（分辨率提升✅），
但"每轮只改一个参数"的铁律把它锁死在 -2.0↔-2.1 死循环，u0 全程冻结——
**单变量下降在非凸误差面上卡进鞍点**：u0=0.17 偏高时，真值 voff=-2.2 的
NRMSE(14%) 反而比 voff=-2.0(11.4%) 差，坐标下降必然回头。

### 事实核查掀桌（转折点）
```
真值组合 (voff=-2.2, u0=0.15):  NRMSE = 11.08%  ← 不是 ≈0！
         (voff=-2.1, u0=0.15):  NRMSE =  9.88%  ← 比真值还好
```
**真值不在 (voff,u0) 两参数张成的空间里**：乙还带 trapmod=2+rontr1=-1，
ron_trap 随 Vg 变化（~0.9-1.25Ω），改变了曲线形状，平移/缩放无法补偿。

### 第三幕：混合架构定型（run_hybrid.py）
```
A. 乙器件：LLM 粗调 3 轮(11.42%) → least_squares 精修
   → NRMSE 2.70%（13 次仿真），但 voff=-2.52/u0=84e-3 远离真值！
B. 干净目标（只差 voff/u0 的合成器件）：7 次仿真 NRMSE=0.0000% 精确命中
```

## 四条核心教训（进 Agent 设计规范）

1. **LLM 粗定位 + 优化器精修 = 工业标准架构**。LLM 负责归因和初值，
   精细收敛交给 least_squares。120 参数的赛题不可能靠 LLM 逐点猜。
2. **RMSE 与参数真值会脱钩**（欠辨识/过参数化补偿）：2.70% 的解参数全错。
   这正是赛题评分"QA通过率 × RMSE"里 QA 存在的意义——**必须加参数物理范围检查**，
   否则优化器交出 u0=84e-3 这种曲线对但物理荒谬的解。
3. **子集提取精度上限 = 未建模差异**。提 voff/u0 时若器件还有陷阱差异没进
   提取空间，残差钉死。提取空间要覆盖主要差异源，或接受 RMSE 残差。
4. **测量分辨率决定提取精度**（第一幕）：观测协议本身是提取质量的上限。
