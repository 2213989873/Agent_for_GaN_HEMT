## 2. 安装 VS Code（若已有可跳过）

1. 官网 https://code.visualstudio.com 下载安装
2. 安装扩展：**Python**（微软官方）、**Pylance**

在仓库根目录的终端（VS Code 里按 Ctrl+`）执行：

```bash
python -m venv .venv
.venv/Scripts/activate        # Git Bash 用这行；PowerShell 用 .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

3. 左侧「API keys」→ 创建 → 复制 key（只显示一次）
4. 把 key 填进 `.env` 文件

## 7. 服务器部署（你的实际环境：A100 远程 Linux + VS Code Remote-SSH）

> 说明：A100 GPU 本赛题基本用不上——我们不训练模型，LLM 走云端 API。服务器的价值在于 **Linux 环境（官方推荐）+ 稳定 + 7×24 挂机**（测试日 24h 窗口不怕断）。

### 7.1 把仓库弄到服务器上（二选一）

**方式 A · zip 快传（今天先用）**
1. 本地已有压缩包 `gan-hemt-agent.zip`（Kimi 生成，含 git 历史）
2. VS Code 连上服务器后，直接把 zip 拖进左侧文件面板即上传
3. 服务器终端执行：
```bash
mkdir -p ~/projects && unzip ~/gan-hemt-agent.zip -d ~/projects/
cd ~/projects/gan-hemt-agent
```

**方式 B · GitHub 私有仓库（本周内建议配好，长期同步中枢）**
```bash
# 本地（Git Bash）
git remote add origin git@github.com:你的用户名/gan-hemt-agent.git
git push -u origin main
# 服务器
git clone git@github.com:你的用户名/gan-hemt-agent.git ~/projects/gan-hemt-agent
```
赛后获奖代码 7 天内本就要求在 GitHub 开源，提前用正合适。

### 7.2 服务器上装环境（conda 或 venv 二选一，不要混用）

**方式一 · conda（实验室服务器推荐）**：无需 sudo、可自选 Python 版本、后期一行装好 ngspice

```bash
cd /data/zhengjp/gan-hemt-agent
conda create -n gan-agent python=3.12 -y
conda activate gan-agent
pip install -r requirements.txt    # 依赖是 PyPI 包，在 conda 环境里照常用 pip 装
```

**方式二 · venv（系统 Python ≥ 3.10 时的轻量选择）**

```bash
cd /data/zhengjp/gan-hemt-agent
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> 两条铁律：① 两种方式**二选一**，别混用；② 无论哪种，以后每次开终端都要先激活环境（`conda activate gan-agent` 或 `source .venv/bin/activate`）再跑代码。

### 7.3 网络连通性检查（重要！实验室服务器常有出口限制）

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://api.deepseek.com
```
返回 200 / 401 / 404 都说明**网络通**（能到达服务器）；**超时**则要找导师/网管开出口，否则调不了大模型 API。测试日还需访问组委会 MeQLab 端点，届时用同样方法验证。

### 7.4 服务器上重建 .env

`.env` 被 git 忽略、也不在 zip 里（防泄露），需在服务器上重建：
```bash
cp .env.example .env   # 然后用 vim/nano 填入真实 key
```

