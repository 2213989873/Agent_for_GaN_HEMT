# 环境搭建指南（Windows）

> 目标：本周内让 `python examples/00_hello_llm.py` 跑通。遇到问题截图发给 Kimi。

## 1. 已就绪（Kimi 已检查）

- Python 3.12.14 ✅（要求 3.10+）
- Git 2.47 ✅

## 2. 安装 VS Code（若已有可跳过）

1. 官网 https://code.visualstudio.com 下载安装
2. 安装扩展：**Python**（微软官方）、**Pylance**
3. 用 VS Code 打开本仓库文件夹

## 3. 创建虚拟环境并安装依赖

在仓库根目录的终端（VS Code 里按 Ctrl+`）执行：

```bash
python -m venv .venv
.venv/Scripts/activate        # Git Bash 用这行；PowerShell 用 .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 4. 注册 DeepSeek API（主力开发模型，便宜）

1. 打开 https://platform.deepseek.com ，手机号注册
2. 完成实名认证 → 充值 10 元（足够整个开发期，百万 token 约 1–2 元）
3. 左侧「API keys」→ 创建 → 复制 key（只显示一次）
4. 把 key 填进 `.env` 文件

## 5. 验证

```bash
python examples/00_hello_llm.py
```

看到「环境验证通过」即完成。
