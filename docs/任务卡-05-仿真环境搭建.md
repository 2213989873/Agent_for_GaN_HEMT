# 任务卡 05：仿真环境搭建（Phase 2 开门任务）

- **阶段**：Phase 2 · 最小闭环 —— 第 1 步：造数据的生产线
- **布置时间**：2026-09-15（Phase 1 收官后）
- **时间预算**：3–5 小时
- **前置条件**：Phase 1 全部任务通过 ✅

## 目标

在服务器上搭好合成数据生产线：**ngspice（仿真器）+ OpenVAF（VA 编译器）+ ASM-HEMT 开源 Verilog-A 模型**。

## 背景（已核实的资源）

- ngspice ≥ 39 内置 OSDI 接口，可直接加载 OpenVAF 编译出的 `.osdi` 模型
- `dwarning/VA-Models` 仓库收录 `asmhemt 101.4.0`，已过 ngspice 兼容性检查（比官方仓库更省事）
- 官方模型仓库 `github.com/asm-hemt` 的 `vacode/` 目录是权威源码（备选来源）
- OpenVAF 提供 Linux x86_64 预编译二进制（openvaf.semimod.de 或 GitHub releases）

## 步骤

### ① 装 ngspice（conda，免 sudo）

```bash
conda activate gan-agent
conda install -c conda-forge ngspice -y
ngspice -v
```

### ② Sanity 仿真（验证仿真器活着）

```bash
mkdir -p /data/zhengjp/gan-hemt-agent/data/sim && cd /data/zhengjp/gan-hemt-agent/data/sim
cat > divider.sp <<'EOF'
* 分压器 sanity test
V1 in 0 10
R1 in out 1k
R2 out 0 1k
.op
.end
EOF
ngspice -b divider.sp
```

看到输出里 `out` 节点电压 ≈ 5V 即正常。

### ③ 确认 OSDI 可用

ngspice 交互模式里输入 `osdi` 命令看是否识别；或 `ngspice -v` 后查编译选项。
**若 conda 版没带 OSDI**（有概率），走备选：源码编译，无需 sudo：

```bash
git clone --depth 1 https://git.code.sf.net/p/ngspice/ngspice ngspice-src
cd ngspice-src && ./autogen.sh && mkdir release && cd release
../configure --enable-osdi --prefix=$HOME/local --without-x
make -j$(nproc) && make install
$HOME/local/bin/ngspice -v
```

### ④ 装 OpenVAF

到 openvaf.semimod.de 的 download 页或 GitHub 搜 "OpenVAF releases"，下载 **linux-x86_64** 预编译包，解压后把可执行文件放进 `~/.local/bin`（或任何 PATH 内目录），验证：`openvaf --version` 或 `openvaf --help`。

### ⑤ 获取并编译 ASM-HEMT 模型

```bash
cd /data/zhengjp/gan-hemt-agent/data/sim
git clone --depth 1 https://github.com/dwarning/VA-Models.git
find VA-Models -iname "asmhemt*.va"    # 找到模型文件
openvaf <找到的asmhemt.va>             # 编译，产出 .osdi
ls -la *.osdi
```
