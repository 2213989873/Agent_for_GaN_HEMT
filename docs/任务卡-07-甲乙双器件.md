- **trapmod**（整数，默认 0=关，0–4）：1=动态陷阱（cdlag/rdlag，τ≈1s，太慢）/ **2=脉冲 I-V 陷阱（rtrap1-3/ctrap1-3，τ≈1–100µs，正合 200µs 窗口）** / 3=动态导通电阻 / 4=RF 陷阱 → **乙选 trapmod=2**

✅ **补档（2026-09-17，shmod 默认值）**：源码 489 行 `` `MPIsw( shmod ,1 ,...)`` —— **shmod 默认就是 1（开）**。所以"乙必须显式 shmod=1"是"确认它开"，不是"默认关"。真正掐住自热脖子的是 dt 引脚：接地 = 等温（ΔT 被钳 0），挂独立节点 = 启用。两个开关是 AND 关系：`shmod==1`（模型内）且 dt 浮地（电路上）。
