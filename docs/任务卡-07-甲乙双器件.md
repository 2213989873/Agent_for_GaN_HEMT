## 目标

给两个虚拟器件开"参数处方"（甲：标准教科书型；乙：强自热 + 强陷阱型），量产第一批"带标准答案"的数据：**DC 输出特性**（Id-Vd 多根 Vg）和**开关瞬态**（陷阱滞后签名）。C-V 和 S 参数（高频小信号类）放任务卡 08。

## 参数地图（先看懂版图，再开处方）

从 228 行参数清单（`data/sim/param_list.txt`，已存档）里，你需要认识的家族：

| 家族 | 代表参数（默认值） | 管什么 | 对应数据 |
|---|---|---|---|
| 直流核心 | `voff`(-2.0V) `u0`(170e-3) `vsat`(1.9e5) `nfactor`(0.5) `lambda`(0) `eta0` | Vth、gm、亚阈摆幅、输出电导 | DC I-V |
| 接触/接入电阻 | `rsc`/`rdc`(1e-4 Ω·m) + `*accs`/`*accd` 一族 | 高端 gm 压缩、膝区 | DC I-V 线性区 |
| **自热** | `rth0`(5 K/W) `cth0`(1e-9) | 饱和区曲线下垂、瞬态热拖尾 | DC 输出特性 |
| **陷阱/滞后** | `remi` `cglag` `cdlag` `rdlag` `atrap*` `btrap*` `rtrap1-3` `ctrap1-3` | 电流崩塌、直流 vs 脉冲差异 | 瞬态/脉冲 |
| 场板 FP1–4 | `vofffp1-4` `dfp1-4` `lfp1-4` 等 | 高压段行为、击穿前形状 | 高压 I-V |
| 电容 | `cgso`/`cgdo`/`cdso`(10fF) `cfg`/`cfd` `cj0` `mz` | C-V、S 参数 | 任务卡 08 |
| 击穿 | `bvdsl`(200V) `asl`(0) | 高压击穿 | 暂不碰 |
| 噪声 | `noia` 等 | 噪声 | 不碰 |
| 结构/实例 | `l`(0.25µm) `w`(200µm) `tbar` `tepi`（实例参数，写实例行不写 .model） | 几何 | 全部 |

**赛题映射**：组委会的"约 120 参数"就是这些；你的 pipeline 将来要按这张地图**分区提取**——每类数据负责锁定一个家族（知识表 1/2/3 的雏形）。

## 步骤

### ① 开关侦查（15 分钟，决定处方前必做）

✅ **已完成（2026-09-16），发现存档**：

- **trapmod**（整数，默认 0=关，0–4）：1=动态陷阱（cdlag/rdlag，τ≈1s，太慢）/ **2=脉冲 I-V 陷阱（rtrap1-3/ctrap1-3，τ≈1–100µs，正合 200µs 窗口）** / 3=动态导通电阻 / 4=RF 陷阱 → **乙选 trapmod=2**
- **自热开关 shmod**（整数）：源码 `if (shmod == 1 && rth0>0)` 才启用热网络 → 乙必须显式 `shmod=1`
- 源码实锤热约定：`Tdev = $temperature + Temp(rth) + dtemp`、`Pwr(rth) <+ Temp(rth)/rth0`——dt 电压 = ΔT，接地 = 等温 ✅
- 注意：整数参数（MPI/IPI 宏）不在 228 行 real 清单里，grep 要分开抓

补一条（确认 shmod 默认值）：

```bash
grep -n "shmod" VA-Models/code/ASMHEMT/vacode/asmhemt.va | head -5
```

### ② 写两张参数处方（30 分钟）

在 `data/sim/` 下建两个文件（**这就是 ground truth，将来 pipeline 的答案**）：

`jia.inc`（甲 = 标准教科书型 = 全默认，一行注释都不改）：

```spice
* 甲器件参数卡：ASM-HEMT 全默认（voff=-2.0 D-mode, rth0=5, 陷阱关）
.model jiamod asmhemt ()
```

`yi.inc`（乙 = 强自热 + 强陷阱；**处方已按 ① 侦查定稿**，看完曲线再微调数值）：

```spice
* 乙器件参数卡：强自热(shmod=1, rth0×4) + 脉冲陷阱(trapmod=2) + 轻微"换 die"偏移
.model yimod asmhemt (
+ voff=-2.2
+ u0=150e-3
+ shmod=1
+ rth0=20
+ cth0=1e-6
+ trapmod=2
+ )
```

处方依据（① 侦查结论）：`shmod=1` 才启用热网络（必须显式写）；`trapmod=2` = 脉冲 I-V 陷阱（rtrap1-3/ctrap1-3，τ≈1–100µs 正合 200µs 窗口）。`rth0=20`（默认 4 倍）：Vd 扫到 12V、Pmax≈4W 时 ΔT≈80K，下垂明显又不离谱；`cth0=1e-6` 使 τ_热≈20µs 落在瞬态窗口内。若 ngspice 报参数不存在，检查拼写（大小写不敏感，但拼写敏感）。

### ③ DC 输出特性（乙的主场，1–2 小时）

`dc_output_yi.sp`（**已修正**：dt 挂独立热节点，不再接地——接地 = ΔT 恒 0 = 自热总闸被拉掉）：

```spice
* 乙器件 DC 输出特性 Id-Vd（Vg 阶梯嵌套扫描）
.include yi.inc
Vd d 0 0
Vg g 0 0
N1 d g 0 0 dt yimod

.control
pre_osdi /data/zhengjp/gan-hemt-agent/data/sim/VA-Models/code/ASMHEMT/vacode/asmhemt.osdi
dc Vd 0 12 0.1 Vg -1.5 1.5 0.5
wrdata dc_output_yi.csv i(vd)
.endc

.end
```

跑：`ngspice -b dc_output_yi.sp`。甲器件对照：`dc_output_jia.sp` = 复制改成 `.include jia.inc` + 实例模型名改 `jiamod` + **dt 保持接地**（甲等温对照组）+ 输出文件名换 jia。

**预期签名**：乙的饱和区曲线应明显**下垂**（Vd 越高 Id 反而缩 = 自热负微分电阻）；甲（dt 接地等温）接近平线。这就是将来 pipeline 提取 rth0 的依据。

✅ **③ 已通关（2026-09-16），存档**：

- **bug 复盘（重要教训）**：首版网表 `N1 d g 0 0 0 yimod` 把 dt 接地，曲线平线（+0.1~0.2%），签名缺失；dt 改挂独立节点后签名立刻出现。原理：`Pwr(rth) <+ Temp(rth)/rth0`——内部热网络往 dt 注功率产生 ΔT，接地则 ΔT 被钳 0。 Kimi Code 自主发现并修复，复核无误。
- **数据签名**（Id@12V 相对 Id@6V，Kimi 侧独立复核一致）：Vg=-1.5→-0.29%，0→-1.80%，+1.5→-2.81%，**下垂随功耗单调增大**；甲对照 +0.1~0.2%（正常输出电导）。自热签名成立。
- **CSV 格式存档**：两列（Vd, i(vd)），847 行 = 7 block × 121 行，block 间无分隔行，靠 Vd 回落分界；第 i 块 ↔ Vg=-1.5+0.5i；电流为负是 SPICE 符号约定，画图取负。
- **调参决定**：-2.8% 属"看得出但温和"，rth0=20 暂不动；④ 跑完后若需加强签名，与陷阱参数**一次迭代**一起调（备选 rth0=40），避免反复重跑。

### ④ 开关瞬态：陷阱滞后签名（1–2 小时）

`tran_pulse.sp`——甲乙**同屏对比**（已按 ③ 的教训预修正：独立漏压源分开测流 + 乙 dt 挂热节点、甲 dt 接地等温对照）：

```spice
* 开关瞬态：关态应力后开闸，看 Id 恢复的陷阱滞后
.include jia.inc
.include yi.inc
Vd  d  0 8
Vd2 d2 0 8
Vg  g  0 PULSE(-3 1 0 0.1u 0.1u 20u 100u)

N1 d  g 0 0 0    jiamod
N2 d2 g 0 0 dt_y yimod

.control
pre_osdi /data/zhengjp/gan-hemt-agent/data/sim/VA-Models/code/ASMHEMT/vacode/asmhemt.osdi
tran 0.05u 200u
wrdata tran_pulse.csv i(vd) i(vd2)
.endc

.end
```

两处预修正的缘由（都已付过学费）：① 两器件并同一漏压源，wrdata 只有一列 `i(vd)` 是合流，必须独立 `Vd2` 分开测；② dt 接地 = 关自热，乙要挂独立热节点 `dt_y`（甲保持接地做等温对照）。跑完 `head -20 tran_pulse.csv` 贴给 Kimi。

**预期签名**：开闸瞬间乙的 Id 明显**低于**甲，随后缓慢恢复（陷阱慢慢放电子 = 电流崩塌后的恢复拖尾）；甲几乎瞬时到位。拖尾时间常数 ≈ 陷阱网络的 R×C——trapmod=2 用的是 rtrap1-3/ctrap1-3 三组网络（默认 τ≈1µs/10µs/100µs 档），若拖尾太快一闪而过就加大 `ctrap1`，太慢看不出恢复就减小 `rtrap1`。若乙完全没拖尾，说明 trapmod 没生效，回 ① 复查。
