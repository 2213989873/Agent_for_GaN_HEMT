# 任务卡 08：C-V 与小信号——电容家族的数据量产

- **阶段**：Phase 2 · 最小闭环 —— 第 4 步：补齐电容维度
- **布置时间**：2026-09-16
- **时间预算**：3–4 小时
- **前置条件**：任务卡 07.5 的 E 验收通过（本地环境复刻 ✅）；任务卡 07 的 ④⑤ 完成（陷阱瞬态 + ground truth 归档）

## 目标

量产**电容数据**：Cgg-Vg（栅电容-栅压）曲线，甲乙双器件。这是参数地图上"电容家族"（cgso/cgdo/cdso/cfg/cfd…）对应的地面真值——将来 pipeline 要从此类曲线里提取电容参数，现在先学会"它长什么样、怎么造出来"。

## 原理速成（先看懂再动手）

- **Cgg = dQg/dVg**：栅压每抬高 1V，栅极上要多堆多少电荷。MOS/HEMT 的栅不是理想平行板，C 随 Vg 变化，这条曲线本身就是器件指纹。
- **怎么测**：给 Vg 一个**恒定斜率的斜坡**（dV/dt 已知且精确），则流进栅极的电流 I_g = C·dV/dt → **C = I_g ÷ (dV/dt)**。这叫"准静态 C-V"，和实验室 LCR 表的低频法等效。
- **为什么用斜坡法不用交流法**：瞬态仿真（tran）是我们已验证的老伙计，wrdata 也熟了；交流法（ac）在 ngspice 里涉及复数后处理，坑多，本卡把它降级为选做对照。
- **预期签名**（甲，默认卡）：Vg ≪ voff（深耗尽）时 C 最小且平；接近 voff 开始抬升（沟道开始形成）；Vg > 0 后趋于饱和——整体一条"**S 形上升后拉平**"的曲线，量级 fF ~ 几十 fF。

## 步骤

### ① cv_gg_jia.sp——甲器件 C-V（30–60 分钟）

在 `data/sim/` 下建（注意 pre_osdi 用**相对路径**，是 07.5 定的新约定，跑的时候必须在 data/sim 目录里）：

```spice
* 准静态 C-V：PWL 斜坡扫 Vg，C = -i(vg)/(dV/dt)
.include jia.inc
Vd d 0 0
Vg g 0 PWL(0 -2  8u 6)
N1 d g 0 0 0 jiamod

.control
pre_osdi VA-Models/code/ASMHEMT/vacode/asmhemt.osdi
tran 0.01u 8u
wrdata cv_gg_jia.csv v(g) i(vg)
.endc

.end
```

- `PWL(0 -2  8u 6)`：t=0 时 Vg=-2V，t=8µs 时爬到 6V——斜率 = 8V/8µs = **1e6 V/s**，这个数是换算 C 的分母，别丢
- dt 照旧接地：C-V 的位移电流微乎其微，不需要自热参与（等温更干净）
- 跑：`ngspice -b cv_gg_jia.sp`，然后 `head -10 cv_gg_jia.csv` 贴给 Kimi
- 预计 csv 有 **3 列**：time、v(g)、i(vg)（wrdata 会自动带上时间列）

### ② 换算画图（交给 Kimi Code 的提示词）

> 读 `data/sim/cv_gg_jia.csv`，3 列分别是 time、v(g)、i(vg)。计算 C = -i(vg)/1e6（斜坡斜率 1e6 V/s），单位换算成 fF（×1e15）。画 C 对 v(g) 的曲线，在 voff=-2V 处画一条竖虚线标注。丢弃首尾各 5 个点（斜坡起止处斜率突变不可信）。存图 `data/sim/cv_gg_jia.png`。

**验收签名**：S 形上升后拉平；量级在几 fF ~ 几十 fF 区间。出现**负电容、无穷大、纯噪声**都是异常的，贴出来别硬扛。

### ③ 乙器件同款对照（30 分钟）

复制改成 `cv_gg_yi.sp`：`.include yi.inc`、实例模型名 `yimod`、输出文件名换 yi，其余不动（**乙的 dt 在这张卡里也要接地**——C-V 是等温测量，别让它自热）。

**预期签名**：乙的曲线形状与甲相似，但整体**向右平移 0.2V**（voff=-2.2 的功劳），饱和段高度可能略低（u0 较小的间接影响）。若乙的 C-V 出现奇怪的回滞/台阶，贴出来——那是陷阱在说话，也是好数据。

### ④ 选做：交流法对照（1 小时，学有余力再做）

用 ac 分析在固定偏置下测单频（1MHz）虚部电流，C = Im(I)/(2πf·Vac)，与斜坡法对比同一偏置点的数值。**这一步的价值不在数据，在"测量方法学"**：同一个物理量，两种独立方法对拍——这正是 Phase 3 里 pipeline 自检思想的预演。做不出来不扣分，跳过。

### ⑤ 归档（15 分钟）


git 提交。C-V 维度入库，参数地图上的"电容家族"有了答案。

## S 参数为什么不在这张卡里（说明，不是任务）

ngspice 编译时我们见过 `S parameter analysis enabled`，它确实能做 S 参数。但三件事的优先级排序是 **DC I-V > C-V > 脉冲 > S 参数**——组委会 24 小时提参赛里，直流和电容是主战场，S 参数（高频小信号）性价比最低，留到 Phase 3 后段有余力再说。知道"它有、我们暂时不碰"即可。

## ✅ 验收存档（2026-09-18，教练自主迭代）

- **斜坡方案修订**：起点 -2V → **-6V**（PWL(0 -6 12u 6)，斜率不变 1e6 V/s）。原因：-2V 恰好在 voff 过渡区，拍不到深耗尽段，看不到完整 S 形
- **实测签名**（各 1208 点收敛）：深耗尽（Vg<-2.5V）C≈0 → voff 附近急升 → 饱和 187fF 缓升。教科书 S 形 ✅
- **甲乙差异**：乙整体**左移 ≈0.2V**（voff=-2.2 提前开通），饱和段一致（187.5fF）。⚠️ 更正：本卡预期写的"右移"**反了**——voff 更负意味着同一 Vg 下沟道更强、电容更大，曲线左移
- **事实核查（重要更正）**：cgso/cgdo=10e-15 的单位是 **F/m 归一化**（源码 1761/1767 行 `qsov = w*nf*cgso*V(...)`），w=200µm 下 overlap 电容仅 **0.002fF**——深耗尽时淹没在数值噪声里。所以深耗尽平台≈0 是正常物理，不是模型缺件；测得的电容几乎全是本征沟道电容
- **乙的陷阱在 C-V 里为什么不说话**（思考题 1 的事实答案）：trapmod=2 只经 voff/cdscd/eta0/ron 四条途径影响电容，前三者处方未开（默认≈1e-9~1e-15），ron 在 Vd=0 时影响≈0；且单向斜坡测不出回滞（回滞需往返扫描协议）。12µs 扫描 vs τ=10µs 陷阱——即使开了耦合也只会轻微滞后
- **归档**：cv_gg_{jia,yi}.sp → data/devices/，csv 归器件子目录，对比图 cv_gg_compare.png
