## B. 装 WSL2 + Ubuntu 24.04（Windows 侧）

1. 右键开始菜单 → **终端管理员**（或 PowerShell 管理员），执行：


**通过标志**：列表里 `Ubuntu-24.04` 的 VERSION 是 `2`。

## D. 工具链三件套

```bash
# D1. 编译依赖（这次有 sudo，一把装齐）
sudo apt install -y build-essential bison flex wget ca-certificates

# D2. ngspice-47（与服务器完全相同的配方）
mkdir -p ~/tools && cd ~/tools
wget --timeout=60 https://sourceforge.net/projects/ngspice/files/ng-spice-rework/47/ngspice-47.tar.gz
# 若 404：浏览器开 https://sourceforge.net/projects/ngspice/files/ng-spice-rework/ 找 47 的真实链接替换
tar xzf ngspice-47.tar.gz && cd ngspice-47
mkdir -p release && cd release
../configure --enable-osdi --without-x --without-readline --prefix=$HOME/local CFLAGS="-O2 -std=gnu11" 2>&1 | tail -5
ls Makefile                   # ← 检查点：不存在就把上面 tail 输出贴给 Kimi，禁止往下走
make -j$(nproc) 2>&1 | tail -5
make install

# D3. PATH + OSDI 验证
export PATH=$HOME/local/bin:$PATH
echo 'export PATH=$HOME/local/bin:$PATH' >> ~/.bashrc
echo -e "osdi\nquit" | $HOME/local/bin/ngspice
```

**通过标志（关键判读）**：输出里出现 `osdi: too few args.` = ✅ OSDI 在（这是"命令存在但参数不够"的意思）；出现 `osdi: no such command` = ❌ 没带 OSDI，熔断贴输出。

```bash
# D4. openvaf（用服务器上已验证的 spiceopus 静态版，零依赖风险）
cd ~/tools
wget --timeout=120 -O openvaf-devel.tar.gz "http://www.spiceopus.si/download/openvaf_devel-x86_64-unknown-linux-gnu.tar.gz"
```

## E. 验收对拍（数据必须和服务器逐位一致）

在 `data/sim/` 下建 `smoke_transfer.sp`（注意：pre_osdi 用**相对路径**，跑的时候必须在 data/sim 目录里）：

```spice
* 冒烟测试：转移特性 Id-Vg（Vd=6V 饱和区）
Vd d 0 6
Vg g 0 0
N1 d g 0 0 0 asmhemtdev
.model asmhemtdev asmhemt ()

.control
pre_osdi VA-Models/code/ASMHEMT/vacode/asmhemt.osdi
dc Vg -2 6 0.1
wrdata transfer.csv i(vd)
.endc

.end
```

```bash
cd ~/projects/gan-hemt-agent/data/sim
ngspice -b smoke_transfer.sp
wc -l transfer.csv            # 必须 81 行
awk 'NR>1{print -$2}' transfer.csv | sort -g | tail -1   # 峰值电流
```

**通过标志**：81 行 + 峰值 **1.59 A**（与服务器任务 06 的结果一致）。一致 = 工具链复刻成功，ground truth 在新机器上可复现。

✅ **E 已通关（2026-09-16），存档**：本地复跑 81 行、峰值 1.59272A，与服务器一致。**查案记录**：本卡网表初版误写 `Vd=0.1`（服务器原版为 `Vd=6`，饱和区转移特性），导致峰值 0.339A 的虚惊；用 Vd∈{0.5, 2, 6} 对照实验锁定真值（0.5→1.171A，2→1.556A，6→1.5927A）。教训：ground truth 对拍时，**网表本身也是答案的一部分**，逐字一致才算数。
